# 데이터 카탈로그

> 반입한 모든 데이터의 목록입니다. **무슨 데이터가 어디에 어떤 상태로 있는지**를 한눈에 보기 위한 문서입니다.
> 나중에 기능을 구현할 때 이 파일만 보면 쓸 수 있는 데이터를 바로 찾을 수 있어야 합니다.
>
> 관리: 배포 Claude · 갱신 도구: `tools/intake.py`

---

## 디렉터리 규약

| 경로 | 내용 | git |
|------|------|-----|
| `data/raw/` | 원본 보관 — **3MB 미만** | 추적 |
| `data/raw-large/` | 원본 보관 — **3MB 이상** | **제외** (`.gitignore`) |
| `data/processed/` | 재편성·경량화한 실사용 파일 | 추적 |
| `data/descriptions/` | 웹사이트 설명문·소개 텍스트. 나중에 앱 화면에 넣을 수 있는 것 | 추적 |
| `data/sources/` | 출처 URL·API 명세·수집 스크립트 메모 | 추적 |

## 상태 값

| 상태 | 뜻 |
|------|-----|
| `raw` | 받아만 놓음. 아직 안 봄 |
| `parsed` | 형식·컬럼 파악 완료 |
| `processed` | 경량화·정규화 완료. 바로 쓸 수 있음 |
| `geocoded` | 좌표까지 확보 |
| `merged` | 앱 데이터(`js/`)에 반영 완료 |
| `hold` | 지금은 안 쓰지만 보관 |
| `reject` | 반입 불가 (사유 기재) |

## 분류 값

`tourist` 관광지 · `festival` 축제·행사 · `restaurant` 모범음식점 · `touristrest` 관광식당업
`hotel` 관광호텔 · `camping` 캠핑장 · `temple` 템플스테이 · `jebu` 제부도 숙박
`touristfacility` 관광편의시설업 · `cinema` 영화상영관
`parking` 공영주차장 · `localcurrency` 지역화폐 가맹점 · `misc` 잡다·미분류 · `desc` 설명 텍스트

## 처리 원칙

1. **원본 보관은 3MB 로 갈립니다.** 3MB 미만은 `data/raw/`(git 추적), 이상은 `data/raw-large/`(로컬 전용).
   `.gitignore` 가 크기를 판정할 수 없어 디렉터리로 강제합니다.
2. **5MB 를 넘으면 전부 읽고 재편성한 뒤 원본을 삭제합니다.**
   기준: 5MB 초과. 필요한 컬럼만 남기고 짧은 키로 바꿔 `data/processed/` 에 저장합니다.
   (선례: `js/localcurrency-static.json` 27,374건이 `{id,n,c,a,lat,lng}` 6키로 4.2MB)
2. **지금 안 쓰는 데이터도 버리지 않고 `hold` 로 보관합니다.**
3. **URL·웹페이지를 받으면** 페이지를 확인하고 API 가 있으면 명세를 `data/sources/` 에 적은 뒤
   가능한 raw 데이터를 전부 받아 옵니다.
4. **설명문은 따로 뺍니다.** 나중에 앱 화면에 넣을 수 있도록 `data/descriptions/` 에 장소별로 저장합니다.
5. **`/home/jovyan/work/` 는 처리 후 원래대로 비웁니다.**
   (`hwaseong_AI/`, `logs/`, `.vscode/`, 사진 폴더는 유지)
6. **주차장·지역화폐는 기존 API 수집분이 정확하므로 덮어쓰지 않습니다.** 새 데이터는 대조 보고만 합니다.

## txt 메모 형식

사용자가 URL 과 내용을 메모장으로 정리해 줄 때는 `---` 로 항목을 구분합니다.

```
https://example.go.kr/data/123
화성시 공중화장실 현황. 위경도 포함.
---
https://example.go.kr/data/456
전통시장 목록
```

`tools/intake.py` 가 이 구분자로 쪼개어 각 블록에서 URL 과 설명을 뽑아냅니다.
