## 파일명 규칙

아래 셋 중 아무거나 쓰면 자동으로 연결된다.

```
{장소이름}.jpg              동탄호수공원.jpg
{장소이름}_{설명}.jpg       동탄호수공원_야경.jpg        ← 한 곳에 여러 장 넣을 때
{읍면동}_{id}_{메모}.jpg    동탄구_20_동탄호수공원.jpg   ← 가장 안전
```

- 앞의 두 규칙은 장소이름이 표의 **이름 칸과 글자 단위로 같아야** 한다 (공백·괄호까지).
- 헷갈리면 세 번째를 쓰면 된다. **id 만 맞으면** 연결되고, 앞뒤 글자는 사람이 읽으라고 붙이는 장식이다.
- 확장자는 jpg / jpeg / png / webp 다 된다. 표의 `권장 파일명` 을 그대로 복사해 쓰는 게 가장 편하다.

> ⚠️ **같은 사진을 여러 장소에 돌려쓰지 말 것.** 2026-08-26 에 그렇게 채워진 162장을
> 전부 걷어냈다. 사진이 없으면 그냥 안 보내면 된다 — 이모지로 정상 표시된다.
> 이제 `tools/build_photo_index.py` 가 같은 해시를 두 장소에 배정하면 즉시 실패시킨다.

## 4. 사진은 있는데 화면에 안 뜨는 것 (추가 촬영 불필요)

아래는 assets 에 사진이 **있는데도** 앱에 안 나온다. 코드 작업(개발 Claude) 영역이다.

| 대상 | 장수 | 막힌 이유 |
|------|-----:|-----------|
| 관광호텔 | 6장 | `js/convenience.js` 소속이라 인덱서(`js/data.js` 만 읽음)가 못 본다 |
| 캠핑장 | 17장 | 위와 같음. 게다가 `js/tourism.js` 캠핑 카드에 `<img>` 자체가 없다 |
| 축제·행사 | 44장 | 축제 카드가 CSS 그라데이션 배너를 써서 사진을 안 쓴다 |

행사 사진 4장(`MARS 2026`, `기림의 날 기념식`, `제10회 보훈가족의날 행사`,
`제81주년 광복절 기념식`)은 `PLACES` 에 항목 자체가 없어 고아다.
특히 `제10회 보훈가족의날 행사.jpg` 는 실물이 **제9회** 행사이고 언론사 워터마크가
박혀 있어 그대로 쓰기 곤란하다.
