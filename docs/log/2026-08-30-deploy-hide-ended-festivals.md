# 끝난 축제를 지우지 않고 숨긴다 — '둘러보는 목록'과 '기간이 이름에 있는 곳'을 가른다

- 담당: 배포 Claude

  란에서는 띄워주고"*

## 1. 무엇이 문제였나

오늘(2026-08-30) 기준 **끝난 축제가 4건** 남아 있었다.

| id | 축제 | 날짜 | 경과 |
|---|---|---|---|
| 276 | 화성시 연등 음악축제 | 2026-05-16 | **106일** |
| 277 | 화성 뱃놀이 축제 | 2026-05-22 ~ 25 | **97일** |
| 86 | 제10회 화성하모니카 페스티벌 | 2026-08-22 | 8일 |
| 84 | 권역별 콘서트 (동탄구) | 2026-08-29 | 1일 |

84·86 은 그냥 자연히 지난 것이다. **276·277 은 성격이 다르다** — 2026-08-26 에
반입될 때 **이미 3개월 지난 5월 행사**였다. §4 파이프라인의 「과거 행사 전체 제거」가
그때 안 지켜졌다.

### 표시 버그는 아니었다

`festStatus()`(`js/calendar.js`)가 `date` 를 파싱해 '종료' 배지를 붙이고, 목록 정렬도
`ended` 를 rank 3 으로 맨 뒤에 둔다. **화면이 거짓말하고 있지는 않았다.**
2026-08-26 에 개발 Claude가 죽은 `status` 필드를 걷어내고 만든 구조가 제 몫을 했다.

그래서 이건 **버그 수정이 아니라 방침 결정**이다.

## 2. 어디서 숨기고 어디서 남기나 — 기준은 '이름에 기간이 있는가'

지우지 않고 숨기기로 한 이상, **어디까지 숨길지**가 실제 문제였다.
축제가 나오는 곳이 7군데인데 성격이 갈린다.

기준을 이렇게 잡았다 — **섹션 이름에 시간 범위가 박혀 있으면 지난 것도 그 범위의 소식이다.**
「이번 주 소식」에서 어제 끝난 행사를 빼면 그 섹션이 거짓이 된다. 반대로 그냥
'축제 목록'은 지금 갈 수 있는 곳을 보여 주는 자리라 끝난 것이 낄 이유가 없다.

| 위치 | 처리 | 왜 |
|---|---|---|
| 추천 탭 축제 목록 (`js/tourism.js`) | **숨김** | 범위 없는 둘러보기 |
| 소식 탭 「행사 전체」 (`js/living.js`) | **숨김** | 〃 |
| 홈 대표 축제 카드 (`js/home.js`) | **숨김** | 〃 |
| 「이번 주 소식」 (`js/living.js`) | **유지** | 이름이 곧 범위. `D+N` 으로 지났음을 이미 밝힌다 |
| 「이번 달 축제」 캐러셀 (`js/home.js`) | **유지** | 〃 — 여기서 빼면 8월 캐러셀에서 84·86 이 사라진다 |
| 축제 캘린더 (`js/calendar.js`) | **유지** | 날짜 기반. 지난 날짜에 마킹이 없으면 그게 더 이상하다 |
| 지도 축제 핀 | **손대지 않음** | 이미 안 그린다 (아래) |

### 지도는 이미 처리돼 있었다

`js/map.js` `buildOverlays` 가 2026-08-26 부터 축제를 아예 그리지 않는다.

> *"축제 정보는 화성시 공식 사이트와 연계돼 있고, 장소보다 '언제 하는가'가 본질이라
> 지도에서 찾을 일이 없다. 게다가 50건 중 21건이 장소 미정이라 시청 좌표를 나선으로
> 흩뿌려 '가짜 위치'에 찍히고 있었다."*

**숨길 코드를 새로 넣을 뻔했다.** 손대기 전에 읽어서 5개 파일이 3개가 됐다.

### 「이번 주 소식」도 이미 맞았다

사용자가 지시한 "이번주 축제 란에서는 띄워주고" 는 **이미 그렇게 되어 있었다**
(`js/living.js:310`).

> *"지난 요일(음수)도 이번 주면 보여 준다 — '이번 주 소식'이니 이미 지난 것도
> 이번 주의 소식이다. `D+N` 으로 지났음을 밝힌다."*

그래서 이쪽은 **한 줄도 고치지 않았다.** 지시의 절반은 이미 구현돼 있었다.

## 3. 어떻게 고쳤나

`js/calendar.js` 의 `festStatus()` 옆에 판정 하나를 두고, 세 곳에서 부른다.

```js
function festBrowsable(place, now) {
  return festStatus(place, now) !== 'ended';
}
```

**`'unknown'` 은 남긴다.** 날짜를 못 읽은 것은 끝났다는 근거가 없다 —
`'ended'` 하나만 거른다. `'2026년 8월 중'` 같은 근사 일정은 그 달이 지나야 `ended` 다
(`festStatus` 가 그 달 말일로 판정한다). 오늘 기준 `id:85` 재즈페스티벌은 아직 살아 있고
9월 1일에 숨는다.

호출부는 전부 `typeof festBrowsable === 'function'` 으로 감쌌다 —
`js/calendar.js` 는 스크립트 순서상 9번째라 `home.js`(4)·`tourism.js`(5)·`living.js`(6)
보다 **뒤에 온다.** 함수 안에서 부르므로 런타임에는 문제가 없지만(§3), 주변 코드가
전부 이 방어를 쓰고 있어 맞췄다.

### 실측

| | 값 |
|---|---|
| 축제 전체 | 50건 |
| `ended` | **4건 → 숨김** |
| `upcoming` 45 · `unknown` 1 | **46건 → 그대로 노출** |

`bash tools/check.sh` **exit 0** (문법 OK · 전역 489 덮어쓰기 0 · 인라인 핸들러 96개 전부 선언).
