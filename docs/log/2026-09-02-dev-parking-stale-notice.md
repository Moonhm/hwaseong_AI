# 낡은 주차 값을 「현재 여유」라고 부르지 않는다 — stale 표시 구현

- 날짜: 2026-09-02
- 담당: 개발 Claude
- 커밋: `TBD`
- 발단: §17 ② 답신에서 내가 받아 둔 몫. 배포 Claude 가 *"서버 변경 불필요 —
  `X-Cache`·`X-Cache-Age` 가 이미 응답에 실려 있고 터널도 통과한다"* 로 답해 착수했다.

---

## 1. 왜 필요한가

`tools/server.py` 는 상류가 죽으면 **낡은 값이라도 준다**(§17 ②). 지도가 통째로 비는 것보다
낫다는 판단이고 나도 찬성했다. 다만 그때 이렇게 덧붙였다 —

> *"낡은 값임이 화면에 드러나야 합니다. 화면 표시는 개발 Claude 몫으로 받겠습니다."*

§1 이 **「낡은 값을 새 값인 척 보여주지 않는다」**를 규칙으로 못박아 두었고,
주차 실시간은 **틀리면 사용자가 헛걸음하는** 이 서비스의 핵심 기능이다.
「빈자리 12면」과 「6시간 전 기준 12면」은 사용자에게 완전히 다른 정보다.

## 2. 서버는 안 건드렸다 — 이미 다 있었다

배포 Claude 확인: `_serve_upstream()` 이 **모든 응답에** 붙이고 있고 Cloudflare 터널도 통과한다.

```
X-Cache: fresh | cache | stale        X-Cache-Age: 0.0
```

본문 스키마를 바꾸는 방안도 있었지만 **헤더가 이미 되는데 스키마를 흔들면**
`js/parking.js` 파싱과 `check_data.py` 대조를 같이 건드리게 된다. 헤더가 싸다.

## 3. 고친 것 — `js/parking.js` 한 파일

### ① 세 곳이 헤더를 버리고 있었다

`fetchParkingAll` · `refreshParking` · `refreshParkingSlide` 가 각자
`fetch(...).then(r => r.json())` 로 **응답 객체를 그 자리에서 버렸다.** 헤더를 읽으려면
`r.json()` **앞에서** 가로채야 해서 `_fetchRealtime()` 한 곳으로 모았다.

### ② `stale` 일 때만 알린다

```
fresh  상류에서 방금 받았다        → 아무 표시 없음
cache  TTL(45초) 안이라 캐시다     → 아무 표시 없음. 45초는 알릴 값이 아니다
stale  상류가 죽어 낡은 값을 준다   → 표시
```

**`age` 로 판정하지 않는다.** 캐시는 요청이 올 때만 갱신하는 지연 방식이라 방문자가 없으면
`age` 는 계속 늘어난다 — 그건 장애가 아니라 트래픽 지표다.
**이 구분을 못 해서 내가 09-02 에 「5.8시간째 갱신 실패」라는 틀린 인계를 올렸다**
([`2026-09-02-deploy-parking-cache-age-answer.md`](2026-09-02-deploy-parking-cache-age-answer.md)).
같은 실수를 코드가 반복하지 않도록 그 이유를 함수 위 주석에 적어 뒀다.

### ③ 화면

카드의 라벨 자체를 바꾼다 — `stale` 이면 **「현재 여유」가 아니라 「여유」**다.
'현재' 라는 말이 거짓이 되기 때문이다. 그 아래 경고 줄을 붙인다.

```
⚠️ 실시간 정보를 받지 못해 6시간 전 기준 값을 보여 드려요. 가시기 전에 전화로 확인해 주세요.
```

문구는 §15 해요체를 따랐다. 전화 확인을 권하는 것은 카드에 이미 `📞` 가 있어서다.

## 5. 안 한 것

- **핀·카운트 뱃지에는 안 붙였다.** 핀은 숫자 두 자리가 들어가는 알약이라 경고를 넣을 자리가
  없고, 사용자가 숫자를 믿고 움직이는 지점은 **카드**다. 필요하면 뱃지에 색만 바꾸는 방식이
  따로 있다.
- **`Access-Control-Expose-Headers` 는 서버에 안 넣었다.** 앱과 같은 오리진이라 지금은 필요
  없다. 다른 오리진에서 시험하면 헤더가 가려지는데, 그때 배포 Claude 에게 요청하면 된다.
- **stale 상태를 토스트로 알리지 않았다.** 60초마다 뜨면 성가시다. 카드를 열었을 때만 보인다.
