# 패널 드래그 핸들 — 날씨·바닷길·설정 패널을 끌어서 닫고 펼치기

- 날짜: 2026-08-26
- 담당: 배포 Claude
- 발단: 사용자 요청 — *"햄버거 메뉴중에 오늘 화성 날씨랑 제부도 바닷길 시간표
  이거 핸들이 작동을 안해 이거 움직이게 해줘야지 근데 얘네는 반대로 위로
  올릴수도있게해서 이게 긴화면으로도 볼수있게 해줄래?"*

> 금지하는 방식이다 — "무엇을 했다"는 남아도 "무엇을 안 했는지"가 빠진다.

## 1. 핸들이 '작동을 안' 했던 게 아니라 처음부터 장식이었다

`.panel-drag-zone` + `.slide-handle` 마크업은 세 패널에 다 있었다. 그런데
어디에도 리스너가 붙어 있지 않았다. 지도 슬라이드 카드(`css/20-map.css` 의
`.slide-drag-zone`)에서 모양만 가져다 쓴 것이라, **보기에는 끌 수 있게 생겼는데
실제로는 아무 일도 안 하는 상태**였다.

사용자가 "작동을 안 해"라고 한 건 고장이 아니라 애초에 기능이 없었다는 뜻이다.
이런 건 고치는 것보다 **왜 있는 것처럼 보였나**가 중요하다 — 손잡이처럼 생긴
것을 두면 사람은 반드시 잡아당긴다.

## 2. 위로도 끌 수 있게 — `max-height` 전환

기존 패널은 `max-height: 50vh` 고정이었다. 확장을 위해 `.expanded { max-height: 92vh }`
상태를 더하고 `transition` 에 `max-height` 를 넣었다.

`height` 가 아니라 `max-height` 인 이유: 내용이 짧은 패널(설정)까지 92vh 로
늘어나면 빈 공간만 커진다. `max-height` 는 상한만 올리므로 내용이 짧으면
그대로 짧다.

| 제스처 | 임계값 | 동작 |
|---|---:|---|
| 위로 스와이프 | 40px | `.expanded` 부착 → 92vh |
| 아래로 스와이프 | 50px | 확장 상태면 축소, 아니면 닫기 |

**임계값이 위아래로 다른 이유**: 아래로 끄는 동작은 '닫기'까지 갈 수 있어
실수 비용이 크다. 위로 펼치는 건 되돌리기 쉬우니 더 가볍게(40px) 뒀다.

## 3. 손가락을 따라 움직이게

`onMove` 에서 `panel.style.transform = 'translate(-50%, Ypx)'` 로 인라인 스타일을
직접 준다. 손을 떼면 인라인을 지워 CSS transition 이 복귀를 맡는다.

`-50%` 를 빠뜨리면 안 된다 — 패널이 `left:50%` + `translateX(-50%)` 로 가운데
정렬돼 있어서, `translateY` 만 주면 **가로 정렬이 통째로 깨져 오른쪽으로 밀린다.**

아래로 끄는 동안에만 따라오게 했다(`if (dy > 0)`). 위로는 따라오지 않는다 —
위로 끄는 건 '펼치기'라 패널이 손가락을 따라 올라가면 상단이 화면을 벗어난다.

## 4. 닫을 때 `.expanded` 를 반드시 떼야 한다

`closeToday()` · `closeTide()` · `closeSettings()` 셋 다에 `classList.remove('expanded')`
를 넣었다. 안 그러면 **92vh 로 펼친 채 닫은 패널이 다음에 열 때도 92vh 로 열린다.**
열기 함수가 아니라 닫기 함수에 넣은 이유는, 닫기 경로가 셋(버튼·딤 클릭·드래그)인데
전부 이 함수들을 지나기 때문이다.

## 5. 하지 않은 것 · 남은 위험

- **`touch-action` 을 지정하지 않았다.** `touchmove` 를 `passive:true` 로 달아
  `preventDefault` 를 못 쓴다. 드래그 중 페이지가 함께 스크롤될 수 있다.
  실기기에서 확인하지 않았다.
- **`document` 에 `mousemove`/`mouseup` 을 zone 개수만큼(3번) 중복 등록한다.**
  `live` 플래그로 막고 있어 오작동은 없지만 깔끔하지 않다.
- **패널 본문의 `overflow-y` 를 확인하지 않았다.** 92vh 로 늘렸을 때 내용이
  그보다 길면 스크롤이 되는지 검증하지 못했다.
- 마우스 커서는 후속 커밋(`5bf214f`)에서 `cursor: grab` / `grabbing` 으로 붙였다.
  사용자가 "잡는 마우스 커서가 안뜨는데?"라고 지적한 뒤였다 — 끌 수 있는 것에는
  커서로도 그렇게 말해야 한다는 걸 처음에 빠뜨렸다.
