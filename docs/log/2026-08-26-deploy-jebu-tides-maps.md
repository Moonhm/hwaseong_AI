## jebu_tide_2026.json 상세

**경로**: `data/processed/jebu_tide_2026.json` (70KB)

**원본 구조** (xlsx 시트 3개):
- `2026년 제부도 통행시간표 (공표자료)` — 2026년 1~12월 공식 시간표 ← **이것만 사용**
- `2025년 제부도 통행시간표 (현장자료)` — 2025년 7~12월 실측
- `2025년 제부도 통행시간표 (편차)` — 공표 대비 실측 차이 (수식 셀, 값 없음)

**xlsx 레이아웃**: 3개월 × 4그룹 = 12개월. 행방향 4블록, 열방향 3개월 병렬.
시간 값 형식: 정수 `HHMM` (예: `1356` → `'13:56'`), 문자열 `'계속통행'`, `None`.

**JSON 스키마**:
```json
{
  "meta": { "title": "...", "place_id": 1, "place_name": "제부도", ... },
  "schedule": {
    "2026-01-01": {
      "cross1": { "open": "계속통행", "close": "13:56" },
      "cross2": { "open": "15:56", "close": "계속통행" }
    },
    ...
  }
}
```

- `cross1` / `cross2`: 1차 / 2차 통행 구간
- `open`: 바닷길 열림(통행 시작)
- `close`: 바닷길 닫힘(통행 종료)
- `"계속통행"`: 해당 방향 제한 없이 통행 가능

**파싱 결과**: 365일 전부 확보 (2026-01-01 ~ 2026-12-31)
