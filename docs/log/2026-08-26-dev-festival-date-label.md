# 축제 날짜 표기를 한 함수로 — `festDateLabel()`

- 날짜: 2026-08-26
- 담당: 개발 Claude (hm8824@naver.com)
- 커밋: `fe83e81`
- 발단: 배포 Claude 가 축제 10건의 `date` 를 `"2026-09-05 ~ 2026-09-06"` 범위로
  채우고(`4a0627b`) 표시 회귀 두 곳을 고쳤다(`4a1ba00`). 남은 자리를 전수로 훑었다.

---

## 1. 깨진 곳은 없었다. 대신 끝나는 날이 사라져 있었다

`date` 를 읽어 화면에 찍는 자리를 전부 grep 했다. 나머지는 전부
`split('~')[0]` 이라 **범위 문자열이 들어와도 깨지지 않는다.** 배포 Claude 가
고친 두 곳(달력 목록·홈 대표 카드)만 통째로 `replace` 를 걸어 깨졌던 것이고,
그건 이미 고쳐져 있었다.

문제는 다른 데 있었다.

| 화면 | 그때 표기 |
|---|---|
| 달력 목록 (`js/calendar.js`) | `09.12 ~ 09.13` |
| 소식 탭 '행사 전체' (`js/living.js`) | `09.12` |
| 추천 탭 관광 목록 (`js/tourism.js`) | `09.12` |
| 'N월의 다른 행사' (`js/tourism.js`) | `09.12` |
| 이번 달 캐러셀 (`js/home.js`) | `09.12 ~` |

**같은 축제인데 화면마다 날짜가 다르다.** 이틀 이상 하는 행사가 목록에서는
하루짜리로 읽힌다. 정조효문화제는 10/3~4 인데 목록에 `10.03` 만 뜬다.
캐러셀은 더 나쁘다 — 끝을 자른 채 물결만 남아 `09.12 ~` 가 된다.

## 2. 왜 고쳤나 — 깨진 게 아니라 갈린 것인데

이건 버그가 아니다. 그런데도 손댄 이유가 있다.

같은 날 낸 사고 두 건이 **전부 같은 형태**였다.

| 사고 | 흩어진 자리 | 고쳐진 자리 |
|---|---:|---:|
| `setFilter` 토글 오용 (`activateLc`) | 4곳 | 3곳 |
| SDK 미로드 조용한 무동작 | 8곳 | 3곳 |
| 축제 날짜 표기 | 6곳 | 2곳 |

같은 일을 하는 코드가 여러 곳에 흩어져 있고 그중 일부만 고쳐진다.
**세 번째로 같은 모양을 봤으면 그건 우연이 아니다.**
그래서 이번에는 자리를 줄이는 쪽으로 갔다.

## 3. `festDateLabel(raw, compact)`

`js/calendar.js` 에 둔다. `festBadge`·`_parseFestDateMeta` 와 같은 파일이다 —
**축제 날짜를 아는 코드가 한 곳에 모여 있어야** 다음에 또 갈리지 않는다.

| 인자 | 결과 | 쓰는 곳 |
|---|---|---|
| `festDateLabel(d)` | `09.12 ~ 09.13` | 달력·홈 대표 카드 (폭이 넉넉하다) |
| `festDateLabel(d, true)` | `09.12~13` | 목록 오른쪽 칸 (실측 45px) |

### 규칙 셋

**연도는 조각마다 뗀다.** 통째로 `replace(/^\d{4}-/)` 를 걸면 앞 연도만 지워져
`09.05 ~ 2026.09.06` 이 된다 — 배포 Claude 가 `4a1ba00` 에서 겪은 그 버그다.

**월 생략은 같은 달일 때만.** `compact` 가 `09.12~13` 으로 줄이는 것은 두 날의
월이 같을 때뿐이다. 지금 10건은 전부 같은 달이지만 데이터는 바뀐다 —
`2026-10-31 ~ 2026-11-01` 은 `10.31~11.01` 로 그대로 둔다.

**근사 일정은 연도만 뗀다.** `"2026년 8월 중"` → `"8월 중"`. `~` 가 없으므로
범위 분기를 타지 않는다.

## 4. 압축형이 기존 칸에 들어가는지 먼저 쟀다

목록 오른쪽 칸은 좁다. 기존 주석에도 *"연도를 남기면 오른쪽 칸이 두 줄로
접힌다"* 는 실측이 적혀 있었다. 그래서 바꾸기 전에 쟀다.

| | 글자 | 폭 | 줄바꿈 |
|---|---|---:|---|
| 기존 | `09.05` | 45px | 없음 |
| 압축형 | `09.05~06` | **45px** | 없음 |

`.pi-right` 칸이 이미 45px 를 잡고 있어 여덟 글자가 그대로 들어간다.
들어가지 않았다면 이 설계는 폐기였다.

## 5. 실측

단위 8케이스 (390×844, 실제 브라우저):

| 입력 | `compact` | 결과 |
|---|---|---|
| `2026-09-12 ~ 2026-09-13` | 아니오 | `09.12 ~ 09.13` |
| `2026-09-12 ~ 2026-09-13` | 예 | `09.12~13` |
| `2026-11-02 ~ 2026-11-05` | 예 | `11.02~05` |

| `null` | — | `''` |

소식 목록의 다일 축제 4건이 전부 `09.05~06` 꼴로 폭 45px, 줄바꿈 없음.

## 6. 리베이스가 `?v=` 를 또 삼켰다

커밋하고 push 하려는데 `version-guard` 가 걸렸다.

배포 Claude 의 `4ac1190` 이 `?v=20260826145` 를 **자기 js 내용으로** 먼저
내보냈는데 내 커밋도 145 를 쓰려 해서, 리베이스가 내 `index.html` 변경을
'이미 적용됨' 으로 보고 흡수했다. 그대로 뒀으면 내 js 4개가 이미 나간 145 를
달게 된다 — 서버가 `?v=` 를 `immutable` 로 내보내므로 받아 간 브라우저는
영영 안 받는다.

내가 `6836bcb` 에서 만든 검사가 정확히 이걸 잡았다. 146 으로 올려 amend 했다.
경위는 [`2026-08-26-dev-cachebust-guard.md`](2026-08-26-dev-cachebust-guard.md) 에 있다.

## 7. 하지 말 것

- **`split('~')[0]` 로 되돌리지 마라.** 좁아 보인다고 시작일만 남기면
  이 문서가 고친 그 상태로 돌아간다. 좁으면 `compact` 를 써라.
- **연도 제거를 문자열 전체에 걸지 마라.** `4a1ba00` 의 버그가 그것이다.
- **`compact` 의 월 생략을 무조건 적용하지 마라.** 달이 다르면 `10.31~01` 이
  되어 11월이 사라진다.
