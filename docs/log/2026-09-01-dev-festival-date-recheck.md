## 0. 사용자 감이 맞았다

`data/CATALOG.md` #28 이 2026-08-26 부터 이렇게 적고 있었다.

> festival5.jsp 원문. 공식 날짜·장소로 id:102·id:118 수정. 신규 id:276·277 추가.
> **나머지 8건은 기존 항목과 일치**

**그 8건 중 2건이 일치하지 않았다.**

## 1. 출처부터 다시 확인했다

축제 데이터의 계보는 이렇다.

```
(초기)     경기데이터드림 2024~2025년 행사 24건
2026-08-19 a9504f3  화성시 공식 대시보드 API(total.hscity.go.kr) 기준 2026년 92건으로 전면 교체
2026-08-19 70885be  지난 행사 44건 제거 (1~7월 전부 · 8/14 이전)
2026-08-25 사용자가 공식 축제 페이지 전문을 제공 → data/raw/20260825_url_pagecopy_fulltext.txt
2026-08-26 그 원문으로 10건 대조 → id:102 장소·id:118 날짜 수정, id:276·277 신규
```

**1차 출처**: `https://tour.hscity.go.kr/NEW/6festival/festival5.jsp`
「2026년 화성시 주요 축제·행사 일정」 (화성시 공식 문화관광 포털)

지금도 살아 있다 — `HTTP 200 / 22,775B`.

## 2. 두 번, 서로 다른 방법으로 쟀다

사용자가 "2번에 걸쳐서" 라고 한 것을 **같은 검사를 두 번**이 아니라
**축이 다른 검사 둘**로 받았다. 같은 방법을 두 번 돌리면 같은 눈먼 곳을 두 번 지난다.

### 1차 — 살아 있는 공식 페이지 ↔ `js/data.js` 직접 대조

공식 표 10행을 파싱해 ISO 로 바꾸고 이름으로 매칭했다.

> ⚠ 첫 시도에서 `△ 범위 다름` 이 4건 떴는데 **내 파서가 종료일을 못 읽은 오탐**이었다.
> `'5. 22.(금) ~ 25.(월)'` 의 뒤쪽 `25.` 에는 월이 없어 정규식이 놓쳤다.
> 앞 월을 물려받도록 고쳐 다시 돌렸다. **오탐을 결과로 보고하지 않았다.**

### 2차 — 2026년 실제 달력의 요일과 대조 (공식 페이지 자체를 의심)

공식이 틀렸을 가능성을 배제해야 1차 결과를 믿을 수 있다.

```
공식 페이지가 적은 (월.일.(요일)) 14쌍 → 2026년 실제 요일과 전부 일치. 오류 0건
```

**공식은 신뢰할 수 있다.** 그러면 어긋난 쪽은 `js/data.js` 다.

### 곁들여 — 08-25 사본 ↔ 지금 원본

원본이 그새 바뀌었을 수도 있어 대조했다. **10건 전부 글자까지 동일하다.**
즉 **원본이 변한 게 아니라 반입할 때 빠뜨린 것**이다.

## 3. 나온 것 — 2건

| **111** | 2026 화성 학생동아리 축제 | **10. 24.(토)** | `"2026년 10월 중"` |

이름이 조금 달라서(공식은 「화성시 평생학습축제」·「화성 학생동아리축제」) 08-26 대조에서
샌 것으로 보인다. **장소가 일치해 같은 행사임이 확인된다** — 화성시민대학 / 동탄센트럴파크.

「10월 중」으로 두면 캘린더에 안 뜨고 D-day 도 못 찍고 종료 판정도 안 된다.
공식이 확정 날짜를 주고 있는데 뭉개 놓을 이유가 없다.

## 4. `data.js` 에 없는 2건은 의도적 부재였다

| 공식 | 왜 없나 |
|---|---|
| 화성 효 마라톤 대회 (5. 5.) | **이미 지난 행사.** `70885be` 가 「1~7월 전부」를 제거했다 |
| 서해안 황금해안길 개통식 | **날짜 미확정**(하반기·10월 말 예정). `2026-08-26-deploy-final-data-memo.md` 가 「개통 후 별도 항목 추가 예정」으로 적어 뒀다 |

**둘 다 누락이 아니다.** 근거를 찾기 전에는 「빠졌다」고 적지 않았다.

## 5. 고친 뒤 3차로 다시 돌렸다

수정이 맞는지는 **같은 검사를 다시 통과하는가**로 본다.

```
공식 10건 대조   일치 8 · 어긋남 0 · 의도적 부재 2
고친 두 건 요일   2026-10-30 금 · 10-31 토 · 10-24 토   ← 공식 표기와 일치
```

## 6. 남은 것

- **`date` 가 모호한 축제가 아직 9건 있다** (`"2026년 9월 중"` 류 8건 + `"미정"` 1건).
  이번에 고친 2건과 달리 **공식 페이지에도 확정 날짜가 없다.** 근거가 없으므로 안 건드렸다.
- `id:106` 은 좌표가 아직 화성시청 폴백(`37.199/126.831`)이다. 장소는 「화성시민대학」으로
  적혀 있으니 지오코딩하면 채울 수 있다 — 다만 좌표는 §17 상 배포 Claude 몫이다.
