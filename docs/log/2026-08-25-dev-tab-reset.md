## 같은 탭 재클릭 = 초기화 (개발 Claude 담당 · 2026-08-25)

> 하단 내비에서 **이미 있는 탭을 다시 누르면** 그 탭에 처음 들어온 화면으로 되돌아간다.
> 4개 탭 전부 동일하게 동작하며, **사용자 데이터는 한 건도 지우지 않는다.**

### 핵심 설계 — `go()` 를 건드리지 않았다

하단 내비 전용 진입점 **`navTap(page)`** 을 새로 만들고, 버튼 4개의 `onclick` 만 바꿨다.

`go()` 에 리셋을 넣지 않은 이유가 결정적이다. `go()` 는 `menuGoTourism`·`goMapFocus`·`goLivingCat`·`_srClick`·`navToFav` 등 **15곳에서 프로그램적으로도 불리고**, 그중 다수가 *이미 그 탭인 상태에서* 불린 뒤 200~400ms 지연 콜백으로 원하는 상태를 세팅한다. `go()` 안에서 리셋하면 그 콜백들이 방금 지운 상태를 다시 세팅해 **깜빡임**이 생긴다. 리셋 트리거는 「사람이 하단 버튼을 누른 순간」 하나뿐이어야 한다.

현재 화면 판정은 `.page.active` 클래스를 그대로 읽는다 — 전역 변수를 새로 두면 DOM 과 어긋날 수 있다. **반드시 `go()` 호출 전에** 읽어야 한다(`go()` 가 매번 전부 remove 후 add 하므로).

### 페이지별 리셋

| 함수 | 파일 | 되돌리는 것 |
|------|------|------------|
| `resetHomePage()` | `js/home.js` | 검색어·결과 패널·포커스, 내 위치 CTA, 관광/생활 토글, 콘텐츠 재렌더 |
| `resetTourismPage()` | `js/tourism.js` | 서브탭 '전체', 축제 상세·캘린더 뷰, 제부도 접기, 가로 스크롤 3곳, 캘린더 이번 달 |
| `resetLivingPage()` | `js/living.js` | 스크롤만 (`go()` 가 이미 `renderLivingPage()` 로 전부 되돌린다 — 또 부르면 두 번 그려 깜빡인다) |
| `resetMapPage()` | `js/map.js` | NP 모드, 슬라이드, 레이어 전부, 칩·배지, 업종 필터바, 내 위치 점, 카메라(HWASEONG/레벨9) |

### 절대 건드리지 않는 것

- **즐겨찾기** `localStorage['hsida_favs']` — 사용자 데이터다. "새로고침"은 저장 데이터를 지우는 게 아니다
- **지오코딩 캐시** `hwaseong_conv_v5_*` — 지우면 수백 건을 다시 지오코딩해 수십 초가 걸린다
- **`lcData`** 4.2MB — 비우면 재다운로드 + 저사양 기기에서 메인스레드 1초 정지
- **GPS 재요청 안 함** — 진행 중인 위치 요청은 세대 토큰(`_nearbyGen`)으로 무효화만 하고, CTA 마크업으로 되돌린다

### 함정 3가지 (실제로 밟았거나 명세가 잡아낸 것)

1. **`setFilter()` 를 리셋에 쓰면 안 된다.** 토글이라 이미 켜진 칩에 부르면 '해제'가 되고, `setFilter('all')` 은 첫 진입에 없는 '전체' 칩을 켜고 카메라까지 옮긴다. 칩 active 는 DOM 에서 직접 지운다.
2. **`exitNearestParkMode()` 대신 `exitNpModeOnly()`.** 전자는 120ms 뒤 콜백이 방금 지운 칩과 레이어를 되살린다.
3. **레이어를 끈 뒤에 카메라를 옮겨야 한다.** `setCenter/setLevel` 이 쏘는 `idle` 에 3개 핸들러가 붙어 있고 전부 visible 플래그로만 가드된다 — 순서를 뒤집으면 옛 레이어가 다시 그려진다.

### 구현 중 실제로 밟은 버그 1건

`resetMapPage()` 첫 줄을 `if (!mapReady || !kakaoMap) return;` 로 시작했더니, **카카오 SDK 가 로드되지 않은 환경에서 재클릭이 아무것도 안 했다.** 칩·슬라이드·배지는 SDK 없이도 클릭되고 클래스가 붙는데 통째로 빠져나간 것이다. DOM 상태는 항상 되돌리고, 지도 객체가 필요한 작업(오버레이·카메라)만 `hasMap` 으로 개별 가드하도록 고쳤다.

### 함께 고친 것

`renderLivingPage()` 의 통계 표기가 `27374`(콤마 없음)로 퇴화하던 것을 `toLocaleString()` 으로 통일했다. 지연 로드 전 `0` 은 「진짜 0곳」이 아니므로 마크업 기본값 `-` 를 유지한다.
