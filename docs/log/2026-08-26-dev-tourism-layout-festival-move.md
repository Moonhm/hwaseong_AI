## 1. 서브탭을 아래로 내렸다

**없애지 않고 내렸습니다.** 지우면 문화재·숙박·캠핑·템플스테이 네 서브탭이
아예 닿을 수 없게 됩니다 — 다른 진입 경로가 없습니다.

원래는 헤더와 함께 `position:sticky` 컨테이너에 묶여 맨 위에 붙어 있었습니다.
자기가 거르는 목록과 **두 블록이나 떨어져 있어서** 무엇을 조작하는 컨트롤인지
알기 어려웠습니다. 목록 바로 위로 옮겼습니다.

```
[전]  헤더 · 서브탭(sticky) → 내 위치 추천 → AI 퀴즈 → 축제 → 목록
[후]  헤더(sticky) → 내 위치 추천 → AI 퀴즈 → 서브탭 → 목록
```

sticky 를 떼어낸 이유가 있습니다. 헤더가 `top:0` 으로 이미 고정돼 있어서,
서브탭까지 붙이려면 **헤더 높이만큼 `top` 을 하드코딩**해야 합니다.
그 값이 어긋나면 칩이 헤더 아래로 파고듭니다. 얻는 것에 비해 깨질 구석이 많아
그냥 콘텐츠와 함께 흐르게 뒀습니다.

서브탭이 빠지면서 sticky 래퍼에 헤더만 남아, `.page-header` 자체가 이미
`position:sticky;top:0` 이므로 래퍼를 통째로 걷어냈습니다.

## 2. 내 위치 추천 버튼을 키웠다

추천 탭 맨 위의 주 진입점이라 한눈에 들어와야 합니다.

| | 전 | 후 |
|---|---|---|
| 세로 패딩 | 18px | 26px |
| 제목 | 14px / 700 | 16.5px / 800 |
| 아이콘 | 30px | 38px |
| 점선 테두리 | 1.5px | 2px |
| 실측 높이 | — | **124px** |

테두리를 함께 올린 이유는, 상자만 키우면 1.5px 점선이 눌려 보이기 때문입니다.
그림자도 옅게 더했습니다.

### 키우고 나서야 드러난 것 — `word-break`

글씨를 키우자마자 **"공영주차장" 이 "공 / 영주차장" 으로 잘렸습니다.**
브라우저 기본값이 한글을 글자 단위로 끊기 때문입니다.
`word-break: keep-all` 로 어절 단위로 넘기게 했습니다.

이건 원래도 있던 문제인데 글씨가 작을 땐 한 줄에 들어가서 안 보였습니다.

## 3. '이번 달 축제' 를 소식 탭으로 옮겼다

날짜가 걸린 정보라 '이번 주 소식' 바로 아래가 맞는 자리입니다.
마크업(`#tourism-festival-header` + `#festival-scroll-wrap`)을 통째로
`#page-living` 의 `#living-news` 아래로 옮겼습니다.

렌더 코드는 **한 줄도 안 고쳤습니다.** `renderFestivalScroll()` 이 id 로만
엘리먼트를 찾아서, DOM 위치가 바뀌어도 그대로 동작합니다.
`boot` 에서 딱 한 번 불리고 `PLACES` 는 불변이라 다시 부를 필요도 없습니다.

### ⚠ 놓쳤으면 큰일날 뻔한 것 — 다른 탭의 요소를 숨기는 코드

`switchTourismSub()` 안에 이런 쌍이 네 군데 있었습니다.

```js
if (fhdr)  fhdr.style.display  = 'none';    // #tourism-festival-header
if (fwrap) fwrap.style.display = 'none';    // #festival-scroll-wrap
```

**id 는 그대로인데 요소만 다른 탭으로 옮겨갔으므로**, 이걸 두면
추천 탭에서 '관광지'나 '문화재' 서브탭을 누를 때마다
**소식 탭의 축제 캐러셀이 통째로 숨습니다.** 사용자는 추천 탭을 만졌는데
소식 탭이 비어 있는, 원인을 찾기 매우 어려운 종류의 버그입니다.
네 쌍을 전부 걷어냈고, 같은 실수를 막는 경고 주석을 그 자리에 남겼습니다.

### 함께 옮긴 것

| 코드 | 전 | 후 |
|------|----|----|
| `#festival-scroll-list` scrollLeft 리셋 | `resetTourismPage` (tourism.js) | `resetLivingPage` (living.js) |
| `setTimeout(updateFestArrows, 60)` | `go()` 의 `page==='tourism'` 분기 | `page==='living'` 분기 |

화살표는 `clientWidth` 를 재서 표시 여부를 정하는데 탭이 숨어 있는 동안은 0 이라
판정이 틀립니다. 그래서 탭이 보이게 된 '뒤' 한 박자 늦춰 부르는 구조를 그대로 유지했습니다.
