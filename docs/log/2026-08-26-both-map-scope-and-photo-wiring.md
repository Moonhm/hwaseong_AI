## 3. 사진 재배선 — `photoThumb()` / `hasPhoto()` 신설

사진을 다 받아 놓고도 축제 50장·문화재 43장(문화재 42곳, 한 곳이 2장)이 정상 동선에서
한 장도 안 보이고 있었다. 원인이 한 곳이 아니라 **일곱 곳이 각자 다르게 안 그리고
있던 것**이라, 개별 수정을 버리고 `js/ui.js` 에 조각 하나를 두었다.

```js
function photoThumb(place, size, fb, cls)   // 없으면 '' 를 돌려준다
function hasPhoto(place)                    // placePhotoAll(place).length > 0
```

- **왜 빈 문자열인가.** 호출부가 `photoThumb(p) || 기존이모지` 로 쓸 수 있다. 사진이
  없는데 `<img>` 를 넣으면 목록 수십 개가 전부 404 를 한 번씩 치고 `onerror` 로 숨는다.
- **왜 7곳에 복붙하지 않았나.** 같은 마크업을 일곱 벌 두면 다음에 또 어긋난다.
  일곱 곳이 제각각이던 것이 바로 이번 사고의 원인이었다.

### 그때 이은 7곳 (커밋 `0a00896` 기준 줄번호)

| # | 화면 | 자리 | 방식 |
|---|---|---|---|
| ① | 추천 탭 관광 목록 | `js/tourism.js:252` | `photoThumb(p, 56, iconContent(p.category))` — `p.category === 'tourist'` 조건 삭제 |

이미지는 `inset:0` 로 슬롯을 꽉 채우는 배경이라 모양이 다르다. 그래서 `hasPhoto()`

`.ph-thumb` / `.ph-thumb-fb` / `.ph-thumb.ph-sm` 을 `css/10-content.css` 에 함께 넣었다.
크기를 클래스로 나누지 않고 인라인 `style` 로 받는 이유는 쓰는 곳마다 값이 달라서다.

### 검사가 내가 놓친 두 곳을 잡았다

칩만 지우고 끝냈으면 이렇게 됐다.

우연히 상쇄돼 태그 검사를 통과하고 있었다. `rs` 를 걷어내자 드러나 함께 고쳤다.

### 데이터 파일을 왜 남겼나

커밋 메시지는 "남긴다" 고만 적고 이유를 안 적었다. 무엇을 지우고 무엇을 남겼는지로
보면 기준은 하나다 — **렌더 코드와 데이터를 갈랐다.** 코드는 다시 쓸 수 있지만
데이터는 배포 Claude 가 3,893건을 지오코딩해 좌표 96.4%(3,754/3,893)를 채워 만든
것이라 되만들기가 비싸다. 지도에서 뺀 것은 '표시 방식' 결정이지 '데이터 폐기'
결정이 아니다.

오늘 다시 확인한 파일 상태:

|---|---|
| `js/restaurants-static.json` | **664,985 bytes** (649 KiB), 최상위 `{meta, rows}`, `rows` 3,754건 |
| `data/restaurants-static.json` | 같은 파일. md5 `f23483bf…` 로 **완전히 동일한 사본이 둘** |

이 파일을 지울지 남길지는 아직 정해지지 않았다. `docs/log/2026-08-26-dev-audit-a11y-optimization.md`

### 5-3. `fcf2f62` 커밋 메시지 자신이 틀렸다 — 검사는 이 파일을 안 지킨다

커밋 메시지: *"FLOOR 항목도 그대로라 파일이 줄면 여전히 검사가 잡는다."*
**틀렸다.** `tools/check_data.py` 의 `FLOOR["restaurants-static.json"] = 3754` 는
무력하다. `check_counts()` 가 `got` 에 이 키를 채우는 코드가 없고, FLOOR 순회는
`g = got.get(k, -1); if g < 0: continue` 로 조용히 건너뛴다(`tools/check_data.py:214-216`).
`PRINTED` 쪽도 `real < 0 → continue` 라 숫자 대조는 원래부터 안 돌았다 — 살아 있던 건
'칩 문구가 있는가' 뿐이었고 그것을 이 커밋이 지웠다.

**실증(저장소는 건드리지 않았다).** 스크래치패드에 `js/ css/ tools/ index.html` 사본을
만들고 `HW_ROOT` 를 그쪽으로 돌린 뒤 `js/restaurants-static.json` 을 `[]` 로 비웠다.

```
원본  → 총 28191건 대조 / FAIL 0 / WARN 0
[]로  → 총 28191건 대조 / FAIL 0 / WARN 0     (총계까지 한 자리도 안 변한다)
```

두 겹으로 무력하다. 설령 다른 json 처럼 `load_json()+len()` 으로 채웠어도 이 파일은
최상위가 `{meta, rows}` 딕셔너리라 `len()` 이 **2** 다. 3,754 를 세려면 `d["rows"]` 를
봐야 한다.
