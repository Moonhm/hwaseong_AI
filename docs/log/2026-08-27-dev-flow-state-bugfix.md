# 흐름·상태 버그 사냥 (2026-08-27, 개발 Claude)

사용자 지적: "야 그리고 버그 너무 많은데 이거검토하고 수정좀해봐."

6갈래로 나눠 찾고(되돌아오기 / 지도 필터 / 지연로드 타이밍 / 탭 리셋 /
슬라이드 카드 / 입력 장치) 각 지적을 적대적으로 반증했다.
**지적 36건 → 확정 28건 → 중복을 합쳐 19개 버그.** 전부 고쳤다.

## 이번에 배운 것

### 1. 스크롤 복원은 '높이 확정' 뒤여야 한다

`_returnFromFestView` 는 `go(page)` 직후 `pg.scrollTop = scroll` 을 넣는다.
그런데 `go('living')` 이 부르는 `renderLivingPage()` 가 목록을 5건으로 **접어**
문서가 3,000px 짧아진 뒤였다. 브라우저가 최대 스크롤로 클램프해서 사용자는
자기 자리가 아니라 페이지 맨 아래에 떨어졌다.

지연을 넣는 것은 답이 아니다(그러면 옛 위치가 한 프레임 보인다).
**떠날 때의 높이를 복원 시점에 재현**해야 한다 → 펼침 여부를 전역에 남긴다.

### 2. '토글' 함수를 '설정' 자리에 쓰면 반대로 동작한다

`setFilter(cat)` 과 `setGuView(gu)` 는 둘 다 같은 값을 두 번 주면 해제된다.
그런데 호출부 셋(즐겨찾기·소식 목록·홈 검색)은 **"이걸 보여줘"** 라는 뜻이었다.
칩이 이미 켜져 있으면 오히려 꺼져서 빈 지도가 됐다.

- `activateParking()` 은 이미 이 문제를 알고 만든 함수였다 — 지역화폐만 없었다.
  → `activateLc()` 신설.
- `setGuView(gu, force)` 로 '항상 설정' 경로를 분리.

> **규칙:** 토글 함수를 새로 만들면 `activate*()` 짝을 같이 만든다.
> 호출부가 '보여줘' 인지 '뒤집어줘' 인지 반드시 구분한다.

### 3. 렌더러가 DOM 을 다시 만들면 그 DOM 의 상태 변수도 같이 되돌린다

`renderHotels()` 가 `#jebu-list-section` 을 `display:none` 인 **새 노드**로
갈아 끼우면서 `_jebuOpen` 은 true 로 남겼다. 다음 클릭이 true→false 로 뒤집히며
이미 숨은 것을 또 숨기고 끝나 '첫 클릭 먹통' 이 됐다.

`resetTourismPage()` 에는 되돌림이 있었지만, 탭을 나갔다 오는 경로
(`navTap` 의 `wasActive=false`)는 그 함수를 거치지 않는다.
**리셋 함수가 아니라 렌더러 안**에 두어야 모든 경로가 한 번에 맞는다.

### 4. 전역 플래그로 '지금 열린 카드' 를 기억하면 안 된다

주차장 카드 자동 갱신을 `_pkSlideId` 로 만들었다가 스스로 되짚었다 —
주차장 카드를 보다가 관광지 핀을 누르면 플래그가 남아, 60초 뒤 자동 갱신이
관광지 카드를 주차장 카드로 갈아치운다.
`#slide-inner [data-pkid]` 로 **DOM 에게 묻는다**. 누가 카드를 덮어써도 안전하다.

### 5. 지연 응답은 사용자가 그 사이 무엇을 했는지 확인하고 반영한다

편의시설 지오코딩은 최대 10초다. 완료 시점의 `_fitConv()` 가 사용자가 맞춰 둔
화면을 화성시 전역으로 되돌렸다.

카카오의 `dragend`·`zoom_changed` 는 프로그램이 옮겨도 뜨므로 구분이 안 된다.
`#kakao-map` / `#zoom-track` 의 `mousedown`·`touchstart`·`wheel`·`input` 을
직접 듣는다 — **입력 장치는 사용자만 만진다.**

### 6. 부분 성공을 'done' 으로 잠그지 않는다

지오코딩 타임아웃으로 21/35 만 나온 카테고리가 `CONV_STATUS='done'` 이 되어,
칩을 몇 번을 껐다 켜도 그 세션 내내 21곳이었다(새로고침해야 복구).
부분 결과는 캐시하지 않는 처리는 이미 있었는데 **상태 잠금은 빠져 있었다.**
누락이 있으면 `idle` 로 두어 다음에 다시 받는다(폭주 방지로 2회 제한).

### 7. 디바운스 타이머는 '닫기' 에서 죽인다

`resetHomePage()` 는 `clearTimeout(_srTimer)` 를 하고 있었다. 그런데
✕ 버튼·바깥 클릭·결과 선택은 `closeHomeSearch()` 만 부르고 타이머를 안 죽여,
닫은 검색 결과가 220ms 뒤 혼자 되살아났다. 그때 입력창은 비고 ✕ 는 숨어 있어
**다시 지울 방법이 없었다.**
한 곳(리셋)만 고치면 나머지 경로가 남는다 → 공통 함수(`closeHomeSearch`)에 둔다.

### 8. 마우스 드래그 스크롤은 click 을 만든다

칩 줄을 끌어 스크롤하면 잡은 요소가 커서를 따라오므로 mousedown/mouseup 대상이
같은 칩이 되고 브라우저가 click 을 쏜다 — 스크롤만 하려던 사람의 필터가 켜지거나
(켜져 있었다면) 꺼져서 지도가 통째로 비었다.
칩은 인라인 `onclick` 이라 **캡처 단계**에서 `stopPropagation()` 해야 막힌다.
