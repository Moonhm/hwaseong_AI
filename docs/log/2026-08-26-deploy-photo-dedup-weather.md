### 7-2. 개발 Claude 인계 3건 — 전부 데이터 결함이 아니었다

#### (a) 지역화폐 좌표 74.8% 중복 → **정상 데이터**

한 좌표에 묶인 20,489건을 주소까지 대조했다:

| 구분 | 건수 |
|------|-----:|

| 주소가 다른 것처럼 보인 것 | 1,110 |

그 1,110건도 실제 차이는 `''`(빈 주소) 대 실주소뿐이었다 —
기존에 알려진 `CEILING["lc.empty_addr"] = 503` 이슈이지 좌표 문제가 아니다.

최다 집중점 `(37.1991733, 127.1151837)` 241건은 전부
`경기도 화성시 동탄구 동탄대로시범길 134` = **카림에비뉴 한 건물**이다.

→ **좌표는 맞다.** 문제는 한 점에 마커 241개가 겹쳐 확대해도 안 갈라지는 것이므로
   지도 렌더링(클러스터링·스파이더링) 작업이다.

#### (b) 축제 `status` 50건 전부 `upcoming` → **죽은 필드**

`status` 를 의미 있게 읽는 코드는 `'ongoing'` 비교 두 곳(`js/map.js:568`, `js/calendar.js:99`)뿐인데,
데이터에 `'ongoing'` 은 **0건**이라 그 분기는 영원히 안 탄다.
`js/today.js:47` 주석도 이미 *"⚠ place.status 로 거르면 안 된다. 50건이 전부 'upcoming' 이라 항상 0건이 된다"* 고 경고하고 있다.

날짜가 실제로 지난 것은 3건뿐이다 (`id:86` 08-22 · `id:276` 05-16 · `id:277` 05-22).

→ 수집 시점 스냅샷을 데이터에 굳혀 두는 구조 자체가 문제다.
   `date` 로 런타임 계산하는 편이 맞고, 그건 코드 작업이다.
   데이터에서 3건만 고쳐도 내일이면 또 틀어진다.

#### (c) 미확정 날짜 11건이 '1일'로 굳는 것 → **파서 버그**

데이터는 정직하다. `date:"2026년 10월 중"` 은 실제로 날짜가 안 정해졌다는 뜻이다.

버그는 `js/calendar.js:17-24` 의 `_parseFestDate()` 다:

```js
var m = str.match(/(\d{4})년\s*(\d{1,2})월/);
if (m) return [m[1], ('0' + m[2]).slice(-2), '01'];   // ← 일자를 '01' 로 하드코딩
```

근사값이라는 사실을 호출부에 전혀 알리지 않아,
`js/today.js:141` 이 `'D-' + it.days` 로 **존재하지 않는 D-day** 를 찍는다
(`"2026년 10월 중"` → `2026-10-01` → `D-36`).

→ 근사 여부를 함께 반환하고, 근사일 때는 배지를 `D-36` 대신 `10월 중` 으로 표시해야 한다.
   데이터에 가짜 날짜를 넣어 해결할 문제가 아니다.

(`76` 하나가 109건 = 54.2%). 문화재 42건 별점은 장소 이름 MD5 해시로 계산된다.

다만 이것은 **이미 `WORKFLOW.md` §4 · §9 에 적혀 있는 알려진 한계**다 —
*"Playwright/Selenium 환경 미지원 → 알고리즘 기반 생성"*, *"결정론적 노이즈(MD5 해시 기반)"*,
한계 표의 *"Kakao Place API 실제 별점 연동"* 미완 과제.

`js/ratings.json`(159건)도 같은 알고리즘의 출력이며 어떤 코드도 fetch 하지 않는다.
`kakaoId` 는 159건 중 **63건만 non-null** 이다
(`tools/check_data.py:43` 주석의 "kakaoId 159건" 은 부정확 — 실측 63건).

정렬·필터·추천에 쓰이는 곳은 **없다.** 표시만 3곳
(`js/tourism.js:272` · `js/home.js:164` · `js/map.js:511`).

→ 가짜 별점을 화면에서 내리려면 `SHOW_RATINGS` 플래그로 3곳을 가리면 된다.
   데이터는 지우지 말 것 — `kakaoId` 63건의 유일한 사본이고,
   `js/ratings.json` 은 `tools/check.sh:187` 이 배포본과 sha256 대조 중이라
   한 바이트만 바뀌어도 상시 FAIL 이 난다.
