### 왜 아무도 못 잡았나

이 세션 초반에 배포 Claude 스스로도 "사진 정상"이라고 보고했는데,

### 주인을 어떻게 특정했나

사용자가 보낸 원본 zip 4개(`화성시 관광지 사진` / `축제_행사 사진` / `캠핑장` / `관광호텔`)의
파일명 라벨을 정답으로 삼았다. 사용자가 직접 붙인 라벨이므로 그 사진의 진짜 주인이다.

zip 을 해시로 풀어 대조한 결과 **중복 97그룹 전부** 원본이 특정됐다 (불명 0건).

```

assets 고유 이미지 211장
zip → assets 반입  208장 (누락 0)
assets 에만 있음     3장 (이전 배치: 스타즈호텔프리미어동탄 · 프로방스율암 · 화성예술의전당)
```

`.hwb-air-box` 의 `padding-left` 를 14→8px 로 줄였는데, **1px도 안 움직였다**.
박스 안 글자만 옮긴 것이고 박스 자체는 그대로였다.

진짜 원인은 `.hwb-cur-info { flex: 1 }` 이었다.
이것이 남은 폭을 전부 먹어 `.hwb-air-box` 를 오른쪽 가장자리로 고정하고 있었다.
`flex: 0 1 auto` 로 바꾸니 아이콘·온도·미세먼지가 왼쪽으로 붙어 정렬된다.
