# 탭 개편 1차 — 관광→추천, 생활→소식

> 개발 Claude · 2026-08-26 · **사용자가 이어서 계속 고칠 예정인 1차 시안**

사용자 요청: 관광 탭을 「추천」, 생활 탭을 「소식」으로. 소식은 확성기 아이콘,
추천은 거기 맞는 아이콘. 안쪽 구성도 개발 Claude가 먼저 제안해 보고 이후 하나씩 수정.

## 내부 id 는 바꾸지 않았다 — 중요

화면 라벨만 바꿨다. `data-page="tourism"` · `"living"` 과 함수명
(`switchTourismSub`·`renderLivingPage`·`resetLivingPage` 등)은 **그대로다.**

| 화면 라벨 | 내부 id | 주 파일 |
|---|---|---|
| 추천 | `tourism` | `js/tourism.js` · `#page-tourism` |
| 소식 | `living` | `js/living.js` · `#page-living` |

id 까지 바꾸면 js 17개 파일과 css 선택자를 전부 건드려야 한다.
**라벨이 또 바뀔 수 있는 1차 시안 단계에서는 이르다.**
라벨이 확정되면 그때 한 번에 개명하는 편이 낫다 — 그 사이의 이름 불일치는
이 표와 `index.html` 주석으로 메운다.

## 아이콘

기존 4개와 같은 양식(`viewBox="0 0 24 24" fill="currentColor"`, Material Design 계열)으로 맞췄다.
`currentColor` 라 `.nav-item.active` 색 상속이 자동으로 따라온다.

- **추천** — 반짝임(`auto_awesome`). 지도(지도)·홈(집)과 형태가 겹치지 않고, AI 추천이라는 성격과 맞는다
- **소식** — 확성기(`campaign`). 사용자 지정

## 안쪽 구성 — 1차 제안

**기존 내용을 하나도 지우지 않았다.** 위에 얹기만 했다. 마음에 안 들면 얹은 것만 걷어내면 된다.

### 추천 탭 — AI 추천 퀴즈 진입을 맨 위로

탭 이름이 '추천'이 되면서 자리가 맞았다. 그리고 **실제 결함을 하나 고친다** —
그전까지 이 기능의 진입점은 사이드 메뉴 배너 **단 1곳**이라 사실상 아무도 못 찾았다.
AI 해커톤 출품작인데 AI 기능이 메뉴 안에 숨어 있던 셈이다.

CSS 는 기존 `.menu-rec-banner` 를 그대로 쓴다. 새 규칙을 만들지 않았다.

### 소식 탭 — 「이번 주 소식」을 맨 위로

시간에 민감한 것이 위로 와야 '소식'이다. `js/living.js` 의 `renderNewsSection()` 이 채운다.

- **PLACES 의 축제만 읽는다** — 새 데이터도 네트워크 요청도 없다
- 오늘부터 30일 이내만, 가까운 순 3건
- 날짜 파싱은 `js/calendar.js` 의 `_parseFestDate()` 재사용 —
  `"2026년 8월 중"` 같은 비ISO 형식이 11건 있어 `new Date()` 에 직접 넘기면 안 된다
- **D-3 이내만 주황 배지.** 전부 강조하면 아무것도 강조되지 않는다
- 기존 생활 정보는 그 아래에 「생활 정보」 제목만 붙여 그대로 뒀다

카드가 아니라 **목록** 형태로 둔 이유 — 바로 아래 「생활 정보」가 카드 격자라,
위도 카드면 두 덩어리가 시각적으로 구분되지 않는다.
