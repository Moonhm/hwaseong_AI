| 성격 | 분량 | 어떻게 바뀌나 |
|---|---:|---|

## 어떻게 나눴는가

```
WORKFLOW.md   587줄  규칙 · 현재 상태 · 담당 분담 · 체크리스트
docs/log/     894줄  작업 기록 14개 파일
```

파일명은 `{YYYY-MM-DD}-{dev|deploy|both}-{주제}.md`.
**각자 새 파일만 만들면 같은 곳을 동시에 고칠 일이 없어 충돌이 구조적으로 불가능해진다.**
날짜와 담당이 파일명에 들어가므로 이름이 겹칠 일도 없다.

`ilmeori` 가 `supabase/migrations/` 를 `0001~0021` 로 관리하며
"기존 파일을 절대 고치지 않고 새 번호를 더한다"로 충돌을 없앤 것과 같은 원리다.

## 결정적 판단 — 절 번호를 다시 매기지 않았다


줄번호 참조는 문서가 바뀌면 반드시 깨진다 — 앞으로도 쓰지 말 것.
