## 1. 먼저 — 넘겨받은 변경을 검증했다

`a8835ad` 는 **`js/data.js` 를 고쳤다.** §17 상 배포 Claude 파일이라, 받아들이기 전에
검증부터 했다. 결론은 **전부 맞다.**

### `dateApprox` 4건 — 실제 코드를 돌려 확인했다

추론하지 않고 `js/data.js` + `js/calendar.js` 를 vm 에 올려 `festStatus` 를 직접 돌렸다.

| id | dateApprox | approx | status | 판정 |
|---|---|---|---|---|
| 86 · 95 · 113 · 126 | true | **true** | ended / upcoming | ✅ D-day 사라짐 |
| 84 (진짜 확정) | false | false | ended | ✅ 회귀 없음 |
| 102 (범위형) | false | — | upcoming | ✅ 회귀 없음 |

**「미확정 4건」이 전수인지도 따로 셌다.** `desc` 에 「미확정/미정」이 든 축제는 **5건**이라
`id:133` 누락을 의심했는데 — 그 건은 `date` 가 `"미정"` 문자열이라 `_parseFestDateMeta` 가
**`null`** 을 내고 `unknown` 으로 빠진다. **애초에 D-day 가 붙을 수 없어 누락이 아니다.**
4건이 정확했다.

### `id:105` 날짜 변경 — 값을 되돌려 시점별로 돌렸다

```
2026-10-15   옛값(10월 중) upcoming   현재값(11월 중) upcoming
2026-11-01   옛값 ended  ←여기서 사라진다   현재값 upcoming
2026-11-05   옛값 ended                    현재값 upcoming   ← 소상공인의 날
```

`desc` 는 「10~11월 중」인데 `date` 만 「10월 중」이라 **11월 1일에 자동으로 `ended`** 가 되어
둘러보는 목록 세 곳에서 조용히 사라질 예정이었다. **주장이 사실이다.** 되돌릴 이유가 없다.

> **§17 경계는 짚어 둔다.** `js/data.js` 는 담당 표상 내 파일이고 `dateApprox` 는 **새 스키마
> 필드**다. 다만 사용자가 *"행사 정보가 안 맞는 것 같다, 확인해봐"* 로 지시했고 §17 이
> 「사용자 지시가 표보다 우선」이라 절차 위반은 아니다. **결과도 맞다.**

## 2. 지오코딩 3건 — 두 경로로 교차검증했다

`id:215` 때와 같은 절차다. §17 이 *"추정 좌표를 대입하지 말 것"* 을 못박아 둔 자리이므로
**한 번 조회하고 끝내지 않았다.**

| id | 장소 | 키워드 검색 | 주소 검색 | 두 값 차이 |
|---|---|---|---|---|
| 103 | 에코센터 | `37.1507861 / 126.9388759` | `37.1515620 / 126.9379814` | **117 m** |
| 106 | 화성시민대학 | `37.2285694 / 126.9687643` | `37.2281558 / 126.9663570` | **218 m** |
| 107 | 안석낚시터 | `37.1606765 / 126.8340134` | `37.1611098 / 126.8339543` | **48 m** |

서로 다른 인덱스(POI / 주소)를 타고도 같은 지점을 가리킨다. 반영값은 **키워드 결과**다 —
§18 의 실측대로 주소 검색은 86%가 행정구역 중심점을 돌려주므로, 장소 그 자체의 좌표인
POI 쪽이 맞다.

### 검산 — 폴백에서 얼마나 떨어져 있었나

```
id:103  화성시청 폴백에서 11.0 km   (봉담읍 하가등안길)
id:106  화성시청 폴백에서 12.6 km   (봉담읍 효행로)
id:107  화성시청 폴백에서  4.3 km   (남양읍 활초길)
```

**셋 다 「지도에서 보기」가 사람을 10km 넘게 엉뚱한 데로 보내고 있었다**(id:107 은 4.3km).

### 동명이인 함정을 하나 피했다

`화성시민대학` 검색에 **`화성시민대학평생교육원`**(향남읍)이 2순위로 나온다. 행사 이름이
「화성시**평생학습**주간행사」라 **평생교육원 쪽이 더 그럴듯해 보인다.** 그러나 데이터의
`address` 는 정확히 `화성시민대학` 이고, 완전 일치하는 1순위(봉담읍 효행로 212)를 택했다.
**이름이 비슷하다는 이유로 다른 시설을 고르면 `id:102` 에코팜 사고의 재판이다.**

경기도 화성시 화성시민대학    → 경기도 화성시 화성시민대학(봉담읍 효행로 212)
