## 1. 먼저 걸린 문제 — `data/` 는 서빙되지 않는다

네 파일 모두 `data/processed/` 에 있었는데 `tools/server.py` 의
`_PUBLIC_DIRS = ("js/", "img/", "assets/", "css/")` 에 `data/` 가 없습니다.
앱이 fetch 해도 서버가 막습니다.

배포 Claude 가 `restaurants-static.json` 에 한 것과 같은 방식으로 `js/` 에 복사했습니다(`2efdb93` 선례).
**파일명은 원본 그대로** 뒀습니다 — `data/processed/` 와 1:1 로 대응돼야 갱신할 때 헷갈리지 않습니다.

| js/ | 크기 |
|-----|------|
| `datalab_naviranking_hwaseong_2026.json` | 36KB |
| `datalab_tourism_stats.json` | 491KB |
| `citytour_courses_hwaseong.json` | 3KB |
| `jebu_tide_2026.json` | 70KB |

**전부 지연 로드입니다.** 첫 화면에서는 한 바이트도 받지 않습니다.
실측으로 확인했습니다 — 첫 화면 JSON 요청은 기존 `parking-static.json` 하나뿐이고,
추천 탭에 들어간 뒤에야 셋이 추가로 잡힙니다. 특히 491KB 짜리를 미리 받으면 안 됩니다.

## 2. 표시 방식 — 미리보기 + 전체 보기

사용자가 제시한 두 안 중 후자를 택했습니다. 앱에 이미 있는
「이번 주 소식 … 전체 보기」와 같은 패턴이라 새로 배울 게 없습니다.

전체 보기는 `#view-datalab` 으로 화면을 갈아끼웁니다 —
축제 상세·캘린더가 쓰는 방식(`showCalendar`/`hideCalendar`)과 동일합니다.
셋을 한 그릇에 담고 `showDatalab(kind)` 이 무엇을 그릴지 정합니다.

| 섹션 | 미리보기 | 전체 보기 |
|------|---------|----------|
| 🔥 화성에서 인기 있는 곳 | 가로 랭킹 카드 8개 | 4개 분류 탭 × 최대 100위 |
| 👥 세대별로 많이 찾는 곳 | 구·연령 칩 + 비율 막대 5개 | 같은 칩 + 전체 30행 |
| 🚌 화성 시티투어 | 가로 코스 카드 6개 | 11코스 + 출발지·요일별 연락처 |

**'전체' 서브탭에서만 보입니다.** 축제·관광지·문화재는 목적이 뚜렷한 목록이라
그 위에 큐레이션이 끼면 방해가 됩니다.
`switchTourismSub`(칩 클릭)과 `go('tourism')`(탭 진입) 두 경로 모두에 걸어야
첫 진입에 빈칸이 남지 않습니다 — 후자를 빠뜨리기 쉽습니다.

## 3. 데이터를 실제로 그려 보고 발견한 것 두 가지

### ⚠ 같은 장소가 두 번 들어 있다

`interest_spots_domestic` 상위가 이렇습니다.

```
1 제부도        자연관광지
2 제부도        자연경관(하천‧해양)
3 동탄호수공원   도시공원
4 동탄호수공원   휴양관광지
```

데이터랩이 **서로 다른 분류 체계를 한 목록에 합쳐** 놓았기 때문입니다.
그대로 그리면 "제부도, 제부도, 동탄호수공원, 동탄호수공원…" 이 되어
쓰는 사람 눈에는 그냥 고장입니다.

이름 기준으로 접었습니다(관심 관광지 100 → **68**). 원본 파일은 건드리지 않고
표시 단계에서만 접습니다 — 데이터는 배포 Claude 소관입니다.

**순번도 다시 매겼습니다.** 처음엔 원본 `rank` 를 그대로 뒀는데, 접힌 만큼
`1, 3, 5 …` 로 건너뛰어 이것도 고장으로 보였습니다(스크린샷으로 확인).
접힌 항목은 같은 장소를 다른 분류로 한 번 더 센 것이므로,
합친 뒤 순번을 다시 매기는 쪽이 사실에 가깝습니다.

### ⚠ 조수 1차/2차가 시간순과 어긋나는 날이 있다

2026-08-26 원본:

```json
{"cross1": {"open": "04:46", "close": "계속통행"},
 "cross2": {"open": "계속통행", "close": "02:51"}}
```

`cross2` 는 **전날 저녁에 열린 구간이 자정을 넘어 이어진 꼬리**입니다.
그래서 이 날은 2차(00:00~02:51)가 1차(04:46~24:00)보다 시간상 **앞**입니다.
차수 순으로 늘어놓으면 "1차 04:46~ / 2차 ~02:51" 이 되어 읽는 사람이 헷갈립니다.

차수 라벨은 공식 표와 대조할 수 있게 그대로 두고, **나열 순서만 시각에 맞췄습니다.**
`open` 이 '계속통행' 이면 그날 0시부터 열려 있다는 뜻이라 맨 앞으로 갑니다.

```
[전]  1차 04:46 ~     2차 ~ 02:51
[후]  2차 ~ 02:51     1차 04:46 ~
```

8/27(1차 05:45~15:41, 2차 17:13~03:12)처럼 정상인 날은 순서가 그대로입니다.

## 4. 제부도 바닷길 — 햄버거 메뉴

제부도는 하루 두 번 길이 잠깁니다. 모르고 가면 못 건너거나 섬에 갇힙니다.
화성 관광에서 가장 실용적인 정보라, 사용자 지시대로 메뉴에 넣되
**'제부도 숙박' 바로 위**에 뒀습니다 — 제부도로 가려는 사람이 먼저 봐야 할 순서입니다.

사이드 메뉴와 같은 '딤 + 하단 슬라이드 패널' 구조입니다.
메뉴에서 열기 때문에 사이드 메뉴(z-index 200대)보다 위(300/310)에 떠야 합니다.

화면 맨 위는 **지금 건널 수 있는지 한 줄**입니다. 초록/빨강으로 갈리고,
두 구간 중 지금 해당되는 쪽에 테두리를 넣어 어느 창인지 바로 보이게 했습니다.
아래로 7일(버튼으로 2주까지), 맨 아래 지도 바로가기와 주의 문구.

`_tideOpenNow` 는 '계속통행' 을 한쪽 끝이 열린 구간으로 다룹니다 —
`open` 만 계속통행이면 0시부터, `close` 만 계속통행이면 자정까지입니다.

**해가 바뀌면**: 이 표는 2026년치뿐입니다. 오늘 날짜가 없으면 조용히 비우지 않고
"오늘 시간표가 없어요 — 이 표는 2026년 기준이에요" 라고 명시합니다.
