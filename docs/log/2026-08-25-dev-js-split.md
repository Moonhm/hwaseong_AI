### 지켜야 할 규칙 2가지

1. **`js/boot.js` 는 반드시 마지막에 로드합니다.** 즉시 실행되는 코드(전역 리스너·IIFE·`DOMContentLoaded`)를 전부 여기 모았습니다. 나머지 9개는 선언만 하므로 순서에 영향받지 않습니다.
2. **`type="module"` 을 붙이면 안 됩니다.** 모듈 스코프가 생겨 전역이 사라지고 `onclick` 122곳이 **전부** 죽습니다. classic script 를 유지하십시오.

`<script src>` 를 원래 인라인 블록이 있던 자리(`index.html:1807~1816`)에 그대로 넣었습니다. 위치를 옮기면 실행 순서가 바뀌므로 옮기지 마십시오.
