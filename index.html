About

화성잇다란?

화성잇다는 경기도 화성특례시의 관광지·축제·맛집·공영주차장·지역화폐 가맹점을 카카오맵 기반으로 통합 제공하는 모바일 여행 정보 앱이에요. 화성시 공식 공공데이터와 실시간 주차 API를 연동해 관광지 159곳, 축제 50건, 지정문화재 42곳, 공영주차장 131개, 지역화폐 가맹점 27,374개의 정보를 한눈에 확인할 수 있어요.

🗺️ 카카오맵 API 🎡 관광지 159곳 🎉 축제 50건 🏛️ 지정문화재 42곳 🅿️ 실시간 공영주차장 지역화폐 가맹점

데이터 출처 및 유의사항

본 서비스는 화성시 공식 관광 포털(tour.hscity.go.kr), 화성시 공식 행사 예약(yeyak.hscity.go.kr), 한국관광 데이터랩, 공공데이터포털에서 제공하는 데이터를 활용합니다.

실시간 주차 데이터 (화성시 스마트파킹) — smartparking.hscity.go.kr 공공 API 기반. 주차 여유 대수는 실시간 추정치로 실제 현장 상황과 차이가 있을 수 있으며, 60초 주기로 자동 갱신됩니다.

지역화폐 가맹점 (희망화성지역화폐) — 화성사랑카드 가맹점 현황 데이터 기반. 등록·폐업 현황은 실시간으로 변동될 수 있으며, 최신 정보는 화성사랑카드 공식 채널에서 확인하세요.

관광지·편의시설 데이터 — 화성시 공식 관광 포털 및 한국관광 데이터랩의 공개 데이터를 기반으로 수집·정비하였습니다. 좌표는 웹 검증을 거쳤으나 100–200m 오차가 있을 수 있습니다. 모범음식점·관광식당 등 편의시설 정보는 화성시 공공데이터 기준이며 현장 상황과 다를 수 있습니다.
